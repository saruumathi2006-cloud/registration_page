# Real-Time Registration Form

A modern, responsive user registration form featuring real-time client-side validation using vanilla JavaScript, CSS3, and HTML5.

## 🚀 Features

- **Real-Time Validation**:
  - **Full Name**: Checks that the name is not empty. Displays an error if missing.
  - **Email Address**: Verifies valid email address format using standard regex. Displays an error if the format is invalid.
  - **Password**: Enforces a minimum length of 6 characters. Displays an error if too short.
- **Dynamic Submit Button**: The "Register" button remains disabled until all fields are completely and correctly validated.
- **Modern User Experience**:
  - Instant visual feedback (green/red borders and messages).
  - Password show/hide toggle.
  - Form submission simulation with success confirmation alert.
- **Zero Dependencies**: Built with pure HTML, CSS, and Vanilla JavaScript.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Responsive Flexbox, Gradient background, Transitions)
- **JavaScript (ES6+)**
